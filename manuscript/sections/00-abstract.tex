\begin{abstract}

To circumvent the prohibitive gas costs of the Ethereum Virtual Machine (EVM), Decentralized Finance (DeFi) protocols are incentivized to adopt a dangerous architectural pattern: state redundancy. Instead of reading expensive global state (e.g., global time) in every transaction, protocols cache these values in local, redundant variables. We reveal that this optimization creates a systematic blind spot: Multi-Variable State-Inconsistency (MV-SI). In this defect class, a transition that partially advances state can violate that obligation even though every affected variable remains locally well-formed.

Although MV-SI sits inside the broader family of inconsistent state updates (ISU), existing automated analyses either target same-variable stale state or study multi-variable cases through manual taxonomies. They do not automatically infer latent cross-variable relations or test whether stale relations reach security- or economically relevant decisions; existing automated ISU checks still focus on whether individual state variables appear to miss updates, leaving MV-SI outside their detection scope.

We present MV-Scan, a static may-analysis for detecting candidate MV-SIs in Solidity programs. This paper systematizes the semantics of MV-SI, develops the first automated detection framework for its class, and provides the first large-scale empirical analysis of its prevalence in the DeFi ecosystem.

MV-Scan infers related persistent variables from predicate co-use and multi-return summaries, two recurring ways in which contracts reveal coherent protocol state. A storage-aware interprocedural analysis then tracks these relations across externally reachable execution contexts and identifies writers that update a proper subset of a relation. For each such writer, MV-Scan searches for an omitted member whose persistent value can subsequently influence control flow, another state update, or an external effect. The resulting witness connects the inferred relation, partial transition, stale-state consumer, sensitive operation, call path, and relevant storage-key constraints.

We evaluate MV-Scan on two complementary corpora. Among 116 published state-inconsistency findings, adjudication identifies 64 MV-SIs, 62 of which have accepted builds. MV-Scan strictly recovers 13 of these 62 cases (21.0\%) when recovery requires agreement on the relationship, desynchronizing transition, and behavioral sink. On 65 buildable Web3Bugs projects, the default configuration achieves 20.5\% candidate-level precision. A precision-oriented configuration reduces the structural candidate population from 2,868 to 550 and achieves 28.5\% precision in an independently sampled audit. Analysis of 1,270 audited candidates shows that 97.6\% contain a genuine protocol relationship, while 83.9\% of non-bugs either lack a desynchronizing transition or restore consistency before the state is consumed.

\end{abstract}
