# ISU-074: 2021-11-streaming#h-08

## Published report facts

- **Root cause:** ts.tokens == 0 causes ts.lastUpdate to remain unupdated.
- **Documented consequence:** Ts.token was miscalculated, resulting in the extraction of more tokens than it should have been.
- **Documented fix:** Update ts.lastUpdate even when ts.tokens is zero.
- **Report:** https://code4rena.com/reports/2021-11-streaming#h-08-tstokens-sometimes-calculated-incorrectly
