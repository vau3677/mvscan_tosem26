# ISU-081: 2022-10-traderjoe#h-05

## Published report facts

- **Root cause:** Exception handling for the zero address (address(0)) and the contract's own address (address(this)) skips _cacheFees updates for these addresses.
- **Documented consequence:** Exploiting faulty accounting logic to bypass proper fee accumulation when collectFees() is called and steal reserve assets.
- **Documented fix:** Modify the skip conditions and add overflow checks.
- **Report:** https://code4rena.com/reports/2022-10-traderjoe#h-05-attacker-can-steal-entire-reserves-by-abusing-fee-calculation
