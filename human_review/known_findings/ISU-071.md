# ISU-071: 2023-04-party#h-08

## Published report facts

- **Root cause:** A mapping for tracking whether a veto vote has been cast is missing.
- **Documented consequence:** Users can vote down the same proposal multiple times, allowing users with a small number of votes to veto any proposal.
- **Documented fix:** Add a hasVoted map to track whether each (party, proposalId, address) triple has already cast a veto vote.
- **Report:** https://code4rena.com/reports/2023-04-party#h-08-vetoproposal-user-can-veto-multiple-times-so-every-proposal-can-be-vetoed-by-any-user-that-has-a-small-amount-of-votes
