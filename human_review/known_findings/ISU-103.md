# ISU-103: 2023-08-verwa#h-03

## Published report facts

- **Root cause:** The add_gauge() function does not initialize the time_weight value when adding a new gauge.
- **Documented consequence:** Initial weights that are not set correctly can result in incorrect calculation of voting rights associated with gauges.
- **Documented fix:** Call change_gauge_weight() when adding a gauge, setting its initial weight to 0.
- **Report:** https://code4rena.com/reports/2023-08-verwa#h-03-when-adding-a-gauge-its-initial-value-has-to-be-set-by-an-admin-or-all-voting-power-towards-it-will-be-lost
