# ISU-016: 2024-09-legion-evm-zenith#h-3

## Published report facts

- **Root cause:** A Boolean flag indicating whether the funds have been withdrawn is missing.
- **Documented consequence:** The withdrawCapital() function can be called multiple times until all remaining capital in the contract is withdrawn.
- **Documented fix:** Add a Boolean flag tokensWithdrawn to indicate whether funds have been withdrawn.
- **Report:** https://github.com/code-423n4/zenith-portfolio/tree/main/reports
