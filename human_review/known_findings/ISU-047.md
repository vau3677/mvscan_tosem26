# ISU-047: 2021-04-marginswap#h-07

## Published report facts

- **Root cause:** There is a lack of mapping to avoid repeatedly depositing the same token.
- **Documented consequence:** Multiple deposits of the same token resulted in duplicate token records in the account. holdingTokens array.
- **Documented fix:** Set the holdsToken map in addHolding() to distinguish different tokens.
- **Report:** https://code4rena.com/reports/2021-04-marginswap#h-07-accountholdstoken-is-never-set
