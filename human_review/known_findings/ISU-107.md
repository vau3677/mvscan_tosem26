# ISU-107: 2023-09-venus#h-01

## Published report facts

- **Root cause:** The stakedAt timestamp is not reinitialized when a user obtains non-revocable Prime tokens.
- **Documented consequence:** Users repeatedly claim Prime token without pledging XVS.
- **Documented fix:** Reinitialize the stakedAt timestamp when issuing non-revocable Prime tokens.
- **Report:** https://code4rena.com/reports/2023-09-venus#h-01-primesol---user-can-claim-prime-token-without-having-any-staked-xvs-because-his-stakedat-isnt-reset-whenever-he-is-issued-an-irrevocable-token
