# ISU-023: 2023-07-basin#h-01

## Published report facts

- **Root cause:** The oracle Pumps is not updated promptly.
- **Documented consequence:** Manipulate the reserves of the current block and thus tamper with the prophecy machine data.
- **Documented fix:** Update the Pumps data immediately after each reserve change.
- **Report:** https://code4rena.com/reports/2023-07-basin#h-01-pumps-are-not-updated-in-the-shift-and-sync-functions-allowing-oracle-manipulation
