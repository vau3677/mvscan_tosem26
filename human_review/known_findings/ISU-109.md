# ISU-109: 2023-04-party#h-07

## Published report facts

- **Root cause:** Decrement the ethAvailable before each contributeFor() call.
- **Documented consequence:** When a contribution fails, the remaining ETH is not correctly calculated and refunded to the user, resulting in the user losing funds.
- **Documented fix:** Move the ethAvailable decrement operation after the contributeFor() call.
- **Report:** https://code4rena.com/reports/2023-04-party#h-07-initialethcrowdfund--reraiseethcrowdfund-batchcontributefor-function-may-not-refund-eth-which-leads-to-loss-of-funds
