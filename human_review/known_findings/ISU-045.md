# ISU-045: 2023-01-timeswap#h-03

## Published report facts

- **Root cause:** The calculation of variables like long0Fees and long1Fees is executed only after the transferFees() function call.
- **Documented consequence:** The incorrect calculation of the long0Fees, long1Fees and other variables used to calculate fees caused the transfer fee to always be zero.
- **Documented fix:** Calculate the actual values of long0Fees, long1Fees, and shortFees before calling transferFees().
- **Report:** https://code4rena.com/reports/2023-01-timeswap#h-03-the-collect-function-will-always-transfer-zero-fees-losing-_feespositions-without-receiving-fees
