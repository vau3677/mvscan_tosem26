# ISU-079: 2021-08-yield#h-02

## Published report facts

- **Root cause:** The _updateRewardsPerToken function early returns when totalSupply is zero.
- **Documented consequence:** When minting for the first time, the user mistakenly received all the rewards from the previous reward period.
- **Documented fix:** Update lastUpdated even when totalSupply is zero.
- **Report:** https://code4rena.com/reports/2021-08-yield#h-02-erc20rewards-returns-wrong-rewards-if-no-tokens-initially-exist
