# ISU-059: 2023-01-astaria#h-16

## Published report facts

- **Root cause:** liensOpenForEpoch is not incremented when purchasing liens.
- **Documented consequence:** When Public Vault A acquired lien tokens, liensOpenForEpoch was not calculated correctly, resulting in an overflow when repaying.
- **Documented fix:** Add a call to increaseEpochLienCount().
- **Report:** https://code4rena.com/reports/2023-01-astaria#h-16-when-public-vault-a-buys-out-public-vault-bs-lien-tokens-it-does-not-increase-public-vault-as-liensopenforepoch-which-would-result-in-the-lien-tokens-not-being-repaid
