## Published report facts

- **Root cause:** In the initLPP function, the LPPMetadata data structure is not initialized.
- **Documented consequence:** Repeatedly calling the initLPP() function modifies the claimedSize and partOffset of LPP, resulting in incorrect state hashing.
- **Documented fix:** Remove unnecessary storage reads in the initLPP function. Additionally, add a check in the squeezeLPP function to ensure that bytesProcessed must be equal to claimedSize.
- **Report:** https://code4rena.com/reports/2024-07-optimism#h-03-lpp-metadata-can-be-altered-after-the-challenge-period-is-over-allowing-incorrect-states-to-be-proven
