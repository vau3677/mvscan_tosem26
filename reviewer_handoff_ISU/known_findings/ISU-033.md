## Published report facts

- **Root cause:** The maximum AVAX allocation per node in the cycle is increased via the increaseAVAXAssignedHighWater() function, rather than being directly updated to the current AVAXAssigned value.
- **Documented consequence:** The attacker manipulates AVAX higher than the actual allocation to obtain more rewards.
- **Documented fix:** Change the previous cumulative update method to directly update to the current AVAXAssigned value.
- **Report:** https://code4rena.com/reports/2022-12-gogopool#h-01-avax-assigned-high-water-is-updated-incorrectly
