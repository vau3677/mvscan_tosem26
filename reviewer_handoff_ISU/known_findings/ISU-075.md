## Published report facts

- **Root cause:** The reward records for this Flywheel are not removed simultaneously when removing the BribeFlywheel.
- **Documented consequence:** It is not possible to add new Flywheel incentives that would affect the protocol functionality.
- **Documented fix:** Remove the reward token assets associated with the Flywheel.
- **Report:** https://code4rena.com/reports/2023-05-maia#h-28-removing-a-bribeflywheel-from-a-gauge-does-not-remove-the-reward-asset-from-the-rewards-depo-making-it-impossible-to-add-a-new-flywheel-with-the-same-reward-token
