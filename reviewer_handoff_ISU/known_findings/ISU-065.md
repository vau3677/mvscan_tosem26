## Published report facts

- **Root cause:** When liquidate() performs clearing operations for multiple users, it uses the same minAssetAmount value and lacks variables for different records.
- **Documented consequence:** The liquidation amount was inaccurate, resulting in losses to both the liquidator and the agreement.
- **Documented fix:** Modify the liquidate() function to enable liquidators to pass multiple minAssetAmount parameter values, so that each value corresponds to a different borrower.
- **Report:** https://code4rena.com/reports/2023-07-tapioca#h-20-_liquidateuser-should-not-re-use-the-same-minimum-swap-amount-out-for-multiple-liquidation
