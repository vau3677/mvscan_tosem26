# ISU-111: 2024-07-munchables#h-05

## Published report facts

- **Root cause:** When the token is transferred from an invalid plot to a valid one, the user's "dirty" flag is not reinitialized.
- **Documented consequence:** Reward calculation was skipped by mistake.
- **Documented fix:** Set the "dirty" flag when the user successfully transfers to a valid plot.
- **Report:** https://code4rena.com/reports/2024-07-munchables#h-05-failure-to-update-dirty-flag-in-transfertounoccupiedplot-prevents-reward-accumulation-on-valid-plot
