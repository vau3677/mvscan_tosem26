# ISU-011: 2022-12-tessera#h-06

## Published report facts

- **Root cause:** The propose() function overwrites the hash of the currently active proposal.
- **Documented consequence:** When an activated proposal is executed while a new proposal is pending, funds are permanently stuck in the contract.
- **Documented fix:** Add an orderHash field to the Listing struct to ensure active and new proposals maintain distinct hash values.
- **Report:** https://code4rena.com/reports/2022-12-tessera#h-06-funds-are-permanently-stuck-in-optimisticlistingseaportsol-contract-if-active-proposal-is-executed-after-new-proposal-is-pending
