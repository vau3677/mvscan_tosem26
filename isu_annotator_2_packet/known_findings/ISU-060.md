# ISU-060: 2022-02-concur#h-01

## Published report facts

- **Root cause:** The reward distribution for old pools is not updated when adding new token pools.
- **Documented consequence:** Users are unable to accurately calculate the rewards they deserve.
- **Documented fix:** Call massUpdate() to refresh rewards for all existing pools before adding a new one.
- **Report:** https://code4rena.com/reports/2022-02-concur#h-01-wrong-reward-token-calculation-in-masterchef-contract
