# ISU-096: 2022-07-golom#h-04

## Published report facts

- **Root cause:** The old delegatee is not removed.
- **Documented consequence:** The old delegators were not deleted, resulting in the same user being able to double-count voting rights by delegating the same token multiple times.
- **Documented fix:** remove the user's old delegation before executing a new operation.
- **Report:** https://code4rena.com/reports/2022-07-golom#h-04-old-delegatee-not-deleted-when-delegating-to-new-tokenid
