# ISU-035: 2022-08-olympus#h-03

## Published report facts

- **Root cause:** The current allowance is not decremented based on existing withdrawal records.
- **Documented consequence:** The attacker can front-run the approval change process to withdraw the previously approved funds early.
- **Documented fix:** Decrement the current allowance based on existing withdrawal records when setting a new allowance.
- **Report:** https://code4rena.com/reports/2022-08-olympus#h-03-trsry-front-runnable-setapprovalfor
