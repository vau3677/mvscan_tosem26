# ISU-068: 2022-07-golom#h-07

## Published report facts

- **Root cause:** During delegate operations, the "Checkpoint memory oldCheckpoint" in the function is only modified in memory and not written to storage.
- **Documented consequence:** The checkpoint is not written correctly, and the user's second delegation operation will not be persisted, resulting in the loss of delegation information.
- **Documented fix:** Change "memory oldCheckpoint" to "storage oldCheckpoint".
- **Report:** https://code4rena.com/reports/2022-07-golom#h-07-_writecheckpoint-does-not-write-to-storage-on-same-block
