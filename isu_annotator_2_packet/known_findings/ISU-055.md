# ISU-055: 2024-03-abracadabra-money#h-01

## Published report facts

- **Root cause:** Reserves updates precede TWAP updates.
- **Documented consequence:** Manipulate reserve values prior to TWAP updates, manipulate prices and profit on subsequent trades.
- **Documented fix:** Advance the execution position of the _twapUpdate() function.
