# ISU-007: 2024-01-renft#h-07

## Published report facts

- **Root cause:** Different hash values corresponding to different orders are lacking.
- **Documented consequence:** Creating multiple similar partially filled orders results in the same order hash value, which allows the partial asset to be locked.
- **Documented fix:** Introduce a random number (nonce) for each order to ensure that the orderHash is unique.
- **Report:** https://code4rena.com/reports/2024-01-renft#h-07-attacker-can-lock-lender-nfts-and-erc20-in-the-safe-if-the-offer-is-set-to-partial
