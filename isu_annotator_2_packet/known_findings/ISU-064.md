# ISU-064: 2022-11-stakehouse#h-08

## Published report facts

- **Root cause:** The idleETH is decremented before LP token burning.
- **Documented consequence:** The reward calculation is wrong, and the attacker calls the withdrawETH() function to steal ETH.
- **Documented fix:** Decrement idleETH only after token burning.
- **Report:** https://code4rena.com/reports/2022-11-stakehouse#h-08-function-withdraweth-from-giantmevandfeespool-can-steal-most-of-eth-because-of-idleeth-is-reduced-before-burning-token
