# ISU-027: 2022-12-forgeries#h-01

## Published report facts

- **Root cause:** The recoverTimelock is not updated with each lottery draw.
- **Documented consequence:** Administrators can bypass the waiting time limit by repeatedly calling lastResortTimelockOwnerClaimNFT() without waiting for the specified time lock period to expire.
- **Documented fix:** Update recoverTimelock with every lottery draw.
- **Report:** https://code4rena.com/reports/2022-12-forgeries#h-01-admin-does-not-have-to-wait-to-call-lastresorttimelockownerclaimnft
