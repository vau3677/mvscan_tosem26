# ISU-029: 2023-11-zetachain#h-06

## Published report facts

- **Root cause:** The user's message field is overwritten with an empty string.
- **Documented consequence:** The target contract cannot be called, which makes the cross-chain message function unable to work properly.
- **Documented fix:** Modify the message field as specified by the user.
- **Report:** https://code4rena.com/reports/2023-11-zetachain#h-06-zevm-cross-chain-messages-ignore-the-user-specified-message-and-prevent-calling-the-destination-contract
