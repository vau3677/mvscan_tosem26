# ISU-010: 2023-02-malt#h-01

## Published report facts

- **Root cause:** The _sendToDistributor() function early returns if amount == 0.
- **Documented consequence:** The cumulative APR was not calculated correctly, affecting the target APR calculation in updateDesiredAPR().
- **Documented fix:** Add conditions and modify the logic in _sendToDistributor() to update the current epoch's cumulative APR with the previous epoch's APR value when the amount is zero.
- **Report:** https://code4rena.com/reports/2023-02-malt#h-01-rewardthrottlecheckrewardunderflow-might-track-the-cumulative-aprs-wrongly
