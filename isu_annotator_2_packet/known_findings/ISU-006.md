# ISU-006: 2022-01-behodler#h-04

## Published report facts

- **Root cause:** Reset the user's pendingFlashDecision to default configuration when processing pending governance decisions.
- **Documented consequence:** The attacker repeatedly calls withdrawGovernanceAsset to steal funds.
- **Documented fix:** Properly clear the user's pendingFlashDecision state in the burnFlashGovernanceAsset() function.
- **Report:** https://code4rena.com/reports/2022-01-behodler#h-04-logic-error-in-burnflashgovernanceasset-can-cause-locked-assets-to-be-stolen
