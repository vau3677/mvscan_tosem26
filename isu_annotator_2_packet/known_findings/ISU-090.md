# ISU-090: 2023-03-polynomial#h-05

## Published report facts

- **Root cause:** The performance fee is not deducted during liquidation.
- **Documented consequence:** The fees deducted when closing a position were not distributed correctly, causing users to lose part of the token value when withdrawing.
- **Documented fix:** Deduct performanceFee from premiumCollected in getTokenPrice().
